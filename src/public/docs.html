OpenAI base URL

optimizedLLM is fully compatible with the OpenAI SDK. Just change the base URL.

JavaScript (OpenAI SDK)

import OpenAI from 'openai';
const client = new OpenAI({
  baseURL: 'https://optimizedllm.netlify.app/v1',
  apiKey: 'gllm_YOUR_API_KEY_HERE',
});
const chat = await client.chat.completions.create({
  model: 'moonshotai/kimi-k2.6-optimizedLLM',
  messages: [{ role: 'user', content: 'Hello!' }],
});

Python (OpenAI SDK)

from openai import OpenAI
client = OpenAI(
  base_url='https://optimizedllm.netlify.app/v1',
  api_key='gllm_YOUR_API_KEY_HERE',
)
chat = client.chat.completions.create(
  model='moonshotai/kimi-k2.6-optimizedLLM',
  messages=[{'role': 'user', 'content': 'Hello!'}],
)
